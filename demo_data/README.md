# demo_data

The demo shown in [README.md](../README.md): Claude Code, over `xipe mcp`, tries the HSL → RGB conversion of
[vaab/colour](https://github.com/vaab/colour) (`hsl2rgb` and `_hue2rgb`) in tezcatl, recorded on 2026-11-22.

| File | What |
|---|---|
| `xipe-demo.mp4` | the whole session (3.5 min): the instruction, the class proposals, the approval, 31 rows evaluated, the agent's report |
| `01-xipe-rows.png` | the 31 rows in tezcatl's table, two of them `eval_error` (saturation and lightness out of range) |
| `02-approval.png` | the agent's class proposals waiting in tezcatl's approval view (`matrix approve`) |
| `03-claude-instruction.png` | the one-line instruction to the agent and its first steps |

Not synced to [xipe_totec_without_nix](https://github.com/Crux-xurC/xipe_totec_without_nix) or the tezcatlipoca tarball.
